# Account Management System Test Plan

Use a fresh application process for each case unless the steps explicitly test multiple operations in one session. The current account balance is held in memory, starts at `1000.00`, and resets when the process is restarted. Run the cases with a stakeholder and record the observed output and Pass/Fail status. Amounts shown below are business values; the current COBOL display format pads the whole-number portion to six digits (for example, `001000.00`).

| Test Case ID | Test Case Description | Pre-conditions | Test Steps | Expected Result | Actual Result | Status (Pass/Fail) | Comments |
| --- | --- | --- | --- | --- | --- | --- | --- |
| TC-001 | View the initial account balance | Start a fresh application process. | Select `1` (View Balance), then select `4` (Exit). | The displayed current balance is `1000.00` (currently formatted as `001000.00`). | TBD | Not Run | Confirms the initial in-memory balance set by `DataProgram`. |
| TC-002 | View the balance repeatedly without changing it | Start a fresh application process. | Select `1` twice, each time after the menu is displayed again, then select `4`. | Both views show `1000.00`; viewing the balance does not change it. | TBD | Not Run | Covers repeated `READ` operations. |
| TC-003 | Credit a whole-number amount | Start a fresh application process with balance `1000.00`. | Select `2` (Credit Account), enter `150`, then select `1` to view the balance. | The credit succeeds and reports a new balance of `1150.00`; the subsequent view also shows `1150.00`. | TBD | Not Run | Confirms addition and persistence within the running process. |
| TC-004 | Credit an amount with cents | Start a fresh application process with balance `1000.00`. | Select `2`, enter `25.75`, then select `1`. | The credit succeeds and the balance is `1025.75` both in the credit confirmation and subsequent view. | TBD | Not Run | Confirms two-decimal amount handling. |

| TC-006 | Debit the exact available balance | Start a fresh application process with balance `1000.00`. | Select `3`, enter `1000.00`, then select `1`. | The debit is allowed because the balance is equal to the requested amount. | TC-007 | Reject a debit one cent above the available balance | Start a fresh application process with balance `1000.00`. | Select `3`, enter `1000.01`, then select `1`. | The application displays `Insufficient funds for this debit.` and does not change the balance; the subsequent view shows `1000.00`. | TBD | Not Run | Confirms rejection and no write on insufficient funds. |

| TC-009 | Continue after an invalid menu choice | Start a fresh application process. | Enter menu choice `5`, select `1` when the menu is displayed again, then select `4`. | The application displays `Invalid choice, please select 1-4.`, remains running, then allows the balance view (`1000.00`) and exits normally. | TBD | Not Run | Covers the menu `WHEN OTHER` path. |
| TC-010 | Exit the application | Start a fresh application process. | 1. Select `4`. | The menu loop ends and the application displays `Exiting the program. Goodbye!`. | TBD | Not Run | Confirms the explicit exit path. |

| TC-012 | Reach the maximum representable balance without exceeding it | Start a fresh application process with balance `1000.00`.
